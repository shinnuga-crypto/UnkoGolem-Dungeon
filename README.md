# 便王号 — うんこ魔導ゴーレムと突然の迷宮

村のうんこを燃料に、じいちゃんの農耕ゴーレムで迷宮へ。歩数と戦利品を管理し、帰還して強化する小さなターン制探索ゲームです。５階の大ぬしを倒して生還すると物語クリア。その先も探索できます。

## ダウンロード・起動

**[最新の配布版はこちら](https://github.com/shinnuga-crypto/UnkoGolem-Dungeon/releases/latest)**

1. リリースの Assets から **`UnkoGolem_Rebalanced_Windows.zip`** をダウンロードしてください。
2. ZIPをすべて展開し、書き込みできる場所に置いてください。
3. **`Play.cmd` をダブルクリック**してゲームを起動します。
4. 「便王号、起動！」→「汲み取り」→「出撃！」で開始できます。

Windows 64bit向け。Godot 4.7.2を同梱しているため、追加インストールは不要です。編集用のGodotソース、操作ガイド、バランス検証レポートもZIPに入っています。

## 操作

| 行動 | キーボード | ゲームパッド（Xbox表記） |
|---|---|---|
| 移動・隣接攻撃 | 矢印 / WASD | 十字キー / 左スティック |
| 決定・ゲート・階段 | Enter / E | A |
| 現地補給 | F | X |
| 現地修理 | R | RB |
| 足踏み | Space | Y |
| 探索メニュー | Esc | B |
| 効果音切替 | M | — |

移動は燃料１、攻撃は燃料２。燃料０か耐久０でその探索の戦利品を失います。青い帰還ゲートへ戻って決定すると素材を持ち帰れます。倉庫・改造・到達記録は失敗しても残ります。

## バランス研究室

**`Simulator.cmd`** から起動します。本編の操作講座からも開けます。

開始階、装備、燃料、行動方針、シード、試行数を変更して、調整前後の帰還率・ボス討伐生還率・持ち帰り鉄・失敗原因を比較できます。１手ずつのリプレイと自動再生も対応しています。ゲームと同じ探索処理を使い、本編セーブには影響しません。

## 改良・検証

- 帰路の点線と必要歩数、耐久・燃料バー
- 鉄くずによる現地修理、燃料ごとの攻撃・修理特性
- ボスの予告攻撃・回避・反撃の隙
- 草・鉄の配置保証、歯車の分解、帰還報告
- 効果音、被弾演出、自動保存と探索途中の再開

６条件×新旧×300シードの比較と、100組ずつの20遠征シミュレーションを実施しました。Godotの実行チェック15,533件を通過し、本編・研究室の起動、実画面、セーブ、戦闘、帰還、エンディングを確認しています。

**ボットは地図を把握しているため、人間の成功率を保証する結果ではありません。物理ゲームパッドの実機確認と長時間の人間プレイ評価は未実施です。**

## セーブ・編集

セーブは展開フォルダーの `userdata/unko_golem_save_v2.json`。やり直す場合はゲームを閉じ、このファイルを別名にするか別フォルダーへ移してください。配布ZIPにプレイ済みセーブは含まれていません。

Godotで編集する場合は、ZIP内の `project.godot` を開いてF5。詳しい説明は同梱の `README.md` と `docs/バランス検証.md` を参照してください。

同梱Godotと第三者コンポーネントのライセンスは `runtime/GODOT-LICENSES.txt` に収録しています。
